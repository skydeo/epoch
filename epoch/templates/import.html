CSV format

  • Columns: Date, Hours, Type, Reason, Requested (header row required).
  • Dates: ISO (2026-07-13) or US (7/13/2026).
  • Type: PTO or Personal Holiday (case-insensitive).
  • Requested: Yes/No or TRUE/FALSE — whether the day is already entered in the HR system.
  • 0-hour rows are skipped — the sheet pads ranges with 0-hour weekend rows; they are not usage.
  • Modes: Replace all deletes the existing log first (destructive, but truly idempotent — re-running the same import is safe); Merge keeps existing rows and skips duplicates on (date, type, hours).
